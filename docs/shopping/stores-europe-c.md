## Next steps

- **sahibinden**: search requires a signed-in session. Options: a residential/unlocker
  provider with a Turkish exit (Bright Data answered HTTP 402 during probing, so it was not
  tested), or a logged-in browser profile through Firecrawl interact (needs an account, which
  this work did not create). Write the row reader only once a real result page is captured.
- **wallapop**: page 2+ is wired (`pagesByCursor`, `nextCursor`, `q.cursor`) and works against
  the API, but the service caps each site token at 500 chars (`service.ts`, cursor decode) and
  Wallapop's token is ~900-930. Raising that cap (and `MAX_CURSOR_CHARS`, 2048, still fits one
  such token) would turn paging on; then drop `MAX_SITE_TOKEN` in `wallapop.ts`.
- **todocoleccion / skelbiu / adverts_ie** run on paid fetches; re-check whether a plain fetch
  starts working before relying on them at volume.
- **dubizzle_ae**: price sort could come from the `by_price_asc_all.com` index if a URL
  parameter for it is found; today mcpy sorts.
